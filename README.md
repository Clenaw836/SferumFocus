# SferumFocus

Веб-приложение для учебных заданий, работы с классом и локального журнала оценок.

## Локальный запуск

Нужны Docker Engine, Docker Compose v2 и интернет для первой сборки.

```sh
docker compose -f compose.jury.yaml up -d --build --wait --wait-timeout 180
```

Открыть: **http://127.0.0.1:8001/?demo=live**

Параметр `demo=live` создаёт отдельную серверную демосессию учителя. В панели демосессии можно переключаться между учителем и учениками. Используются вымышленные данные, реальные школьные аккаунты и ключи не нужны. СГО, боты и внешний AI в этой конфигурации отключены.

Если порт занят, в Bash можно выбрать другой:

```sh
JURY_PORT=8002 docker compose -f compose.jury.yaml up -d --build --wait --wait-timeout 180
```

Тогда открыть `http://127.0.0.1:8002/?demo=live`. Не останавливайте чужие контейнеры ради освобождения порта.

## Кабинет учителя

Разделы «Урок и задания», «Табель» и «Инструменты» открываются отдельно. «Журнал оценок» доступен подтверждённому аккаунту учителя вне демопесочницы.

В разделе «Инструменты»:

- **Критерии оценивания.** До 8 критериев, собственные максимальные баллы и пороги оценок. Калькулятор показывает баллы, процент и рекомендуемую оценку 2–5. В журнал и СГО результат автоматически не записывается.
- **Банк комментариев.** Личные шаблоны обратной связи: сохранить, открыть, изменить, удалить, скопировать. Автоматических сообщений ученикам или родителям нет. Перед копированием замените примеры конкретными наблюдениями.
- **План урока.** Цель, длительность 10–120 минут и до 10 этапов. Видны занятые минуты и резерв; план с превышением длительности не сохраняется. Готовый план можно скопировать.

Шаблоны хранятся на сервере отдельно для каждого владельца, до 100 на аккаунт. Сохраняйте изменения перед переходом к другому инструменту или разделу. При конфликте двух вкладок обновите список и заново выберите шаблон; чужие изменения не перезаписываются молча.

В демосессии инструменты доступны учителю, недоступны ученику и изолированы от обычных аккаунтов. После завершения демосессии её шаблоны удаляются; просроченные записи дополнительно очищаются при обращении к хранилищу.

## Табель учителя

Откройте раздел «Табель» в кабинете учителя. Доступны:

- весь класс или один ученик;
- все предметы или выбранный предмет;
- произвольный период и поиск по имени;
- отбор черновиков, подтверждённых записей и записей, требующих сверки;
- сводка по ученику и предмету либо подробный список каждой оценки;
- экспорт в Excel XLSX, CSV с разделителем `;`, TSV, JSON и HTML.

Для PDF скачайте HTML, откройте его в браузере и выберите «Печать → Сохранить как PDF». Это печатный экспорт, а не отдельный PDF-генератор.

В демопесочнице табель содержит синтетические оценки и отмечен «Демоданные». У обычного аккаунта учителя используются только записи его собственного журнала приложения. Демоданные не смешиваются с пользовательскими записями.

Средний балл справочный, без весов работ; это не официальная четвертная или годовая оценка. Табель не подтверждает полноту школьного журнала. Нет записи — нет оценки, а не двойка. Записи с неизвестным результатом отправки требуют сверки с СГО, автоматически повторно не отправляются.

Интерактивная таблица показывает последние 30 оценок в строке; экспорт содержит все записи выбранной выборки. Большие таблицы открываются порциями по 100 строк. Локальный отчёт ограничен 10 000 исходных записей владельца и явно сообщает о превышении лимита.

## Проверка контейнера

```sh
docker compose -f compose.jury.yaml ps
docker compose -f compose.jury.yaml logs --tail 100 app
docker compose -f compose.jury.yaml exec -T app python - < scripts/jury_smoke.py
```

Последняя команда предназначена для Bash/WSL/Git Bash. Альтернатива для PowerShell:

```sh
docker compose -f compose.jury.yaml cp scripts/jury_smoke.py app:/tmp/jury_smoke.py
docker compose -f compose.jury.yaml exec -T app python /tmp/jury_smoke.py
```

Проверка включает демосессии, переключение ролей, запрет реального дневника, табель, пять форматов экспорта, сохранение/изменение/удаление шаблонов, расчёт по критериям и отказ ученику. Это smoke API, не полный браузерный E2E.

## Данные и безопасность

`jury.env` содержит только публичные демонастройки. Настоящий `.env` и рабочая БД не входят в комплект. Тестовые ключи генерируются при запуске и хранятся в отдельном Docker-томе. Не подменяйте его боевыми данными и не добавляйте реальные токены в демопрофиль.

Файлы обычного табеля содержат персональные данные. Передавайте их только тем, у кого есть право доступа. Значения в CSV/TSV защищены от интерпретации пользовательского текста как формулы; XLSX хранит такой текст как строку.

Остановка без удаления данных:

```sh
docker compose -f compose.jury.yaml down
```

Удаление данных только этой демонстрации:

```sh
docker compose -f compose.jury.yaml down --volumes
```

Не используйте `docker system prune`. Не выставляйте демопрофиль в интернет как production-сервис.

## Экспорт образа

После успешной сборки и проверки:

```sh
set -o pipefail
docker save sferumfocus:jury | gzip -6 > ../sferumfocus-jury.tar.gz
gzip -t ../sferumfocus-jury.tar.gz
sha256sum ../sferumfocus-jury.tar.gz > ../sferumfocus-jury.tar.gz.sha256
```

На другой машине:

```sh
docker load -i /path/to/sferumfocus-jury.tar.gz
docker compose -f compose.jury.yaml up -d --no-build --wait --wait-timeout 180
```

ZIP содержит исходники, не готовый Docker-образ. Dockerfile устанавливает lock-зависимости, проверяет TypeScript и собирает интерфейс. Перед использованием обязательны успешная сборка и проверка контейнера на целевой машине. При ошибке сборки не используйте старый `app/static` как подтверждение работы новых экранов.

Новый экран ввода оценок для подтверждённых аккаунтов не включается для демоперсон. В песочнице можно проверить табель, но не настоящий вход в СГО и отправку оценок.
